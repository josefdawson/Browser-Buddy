Firebase Setup (for real tracking)

To enable real live user tracking:

  1. Go to console.firebase.google.com and create a free project.
  2. Enable Realtime Database (start in test mode for simplicity).
  3. Copy your Firebase config from Project Settings.
  4. Open presence.js and replace the FIREBASE_CONFIG values.
  5. Set database rules to allow read/write: { "rules": { "presence": { ".read": true, ".write": true } } }
  6. Redeploy your site.

Until configured, live users show as "Firebase not configured."
